🎯 WHAT IS TCRM?

TCRM is a professional Point of Sale (POS) system designed specifically for 
restaurants and quick-service establishments. It enables:

  ✓ Manage tables and orders in real-time
  ✓ Inventory management
  ✓ Payment processing and cash management
  ✓ Sales reporting and analytics
  ✓ Kitchen ticket printing
  ✓ User management with role-based permissions


⚡ SYSTEM REQUIREMENTS

  • Windows 10 or later (64-bit recommended)
  • Minimum 500 MB free disk space
  • Administrator privileges required for installation


📥 QUICK INSTALLATION

1. Double-click "INSTALAR_TCRM.bat"

2. If prompted for administrator permission, click "YES"

3. The installer will:
   - Copy TCRM to C:\Program Files\TCRM
   - Create a desktop shortcut
   - Add TCRM to your Start menu
   - Register the application with Windows

4. Once installation completes, you can:
   - Search for "TCRM" in the Start menu
   - Use the desktop shortcut
   - Uninstall via Control Panel

🐛 TROUBLESHOOTING

If you encounter issues:

1. Verify you're running Windows 10 or later
2. Run the installer with administrator rights (right-click → Run as administrator)
3. Ensure you have at least 500 MB free space on C:\


📞 SUPPORT

When reporting issues, please provide:
- Your Windows version
- The step where the failure occurred
- Exact error message (if any)


🔄 UNINSTALLATION

To remove TCRM:

Option 1: Control Panel
  Control Panel → Programs → Programs and Features
  Find "TCRM - Sistema POS" and click "Uninstall"

Option 2: Installation Folder
  C:\Program Files\TCRM\Desinstalar_TCRM.bat
