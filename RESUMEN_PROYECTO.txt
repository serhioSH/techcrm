¿QUE ES TECHCRM-POS?
================================================================================

TECHCRM-POS es un sistema punto de venta (POS) profesional para restaurantes
y establecimientos de comida rápida.

CARACTERÍSTICAS PRINCIPALES:
- Gestión de mesas y pedidos
- Control de inventario de productos
- Procesamiento de pagos y cobros
- Reportes de ventas en tiempo real
- Sistema de cajas con cierre diario
- Gestión de usuarios con permisos
- Impresión térmica de tickets
- **Actualizaciones automáticas desde GitHub**
- Interfaz amigable con PySide6

USUARIOS OBJETIVO:
- Restaurantes de comida rápida
- Cafeterías
- Pequeños establecimientos de alimentos
- Administradores de sucursales

PROBLEMAS RESUELTOS
================================================================================

PROBLEMA 1: ModuleNotFoundError en screens
-------------------------------------------
SÍNTOMA: Al hacer clic en menú, error: "No module named 'app.ui.screens'"
CAUSA: PyInstaller no incluía los módulos de pantalla en el bundle
SOLUCION: 
- Actualizado main.spec con lista explícita de hiddenimports
- Agregado datas para incluir directorio completo
- Probado con todas las 11 pantallas
RESULTADO: ✅ Todas las pantallas cargan correctamente

PROBLEMA 2: Configuración GitHub no persiste
---------------------------------------------
SÍNTOMA: URL de GitHub se perdía al reiniciar la app
CAUSA: Se guardaba en archivo temporal (versioninfo.json)
SOLUCION:
- Cambio a usar ConfigManager
- Guardar en %LOCALAPPDATA%\TECHCRM\config.json
- Configuración persiste entre sesiones
RESULTADO: ✅ Configuración persistente comprobada

PROBLEMA 3: Imports dinámicos incompatibles
-------------------------------------------
SÍNTOMA: Error con __import__() en modo compilado
CAUSA: __import__() no funciona bien con PyInstaller
SOLUCION:
- Cambio a importlib.import_module()
- Compatible con PyInstaller
RESULTADO: ✅ Imports funcionan en .exe compilado

PROBLEMA 4: Compilación inicial fallaba
-----------------------------------------
SÍNTOMA: PyInstaller no encontraba módulos
CAUSA: main.spec incompleto
SOLUCION:
- Reescrito main.spec desde cero
- Agregado todas las dependencias
- Incluido todas las carpetas de datos
RESULTADO: ✅ Compilación exitosa

FLUJOS PRINCIPALES
================================================================================

FLUJO 1: USUARIO INICIA LA APP
1. Usuario abre TECHCRM-POS.exe
2. App verifica base de datos (crea si no existe)
3. Se carga pantalla de login
4. Usuario ingresa credenciales
5. Sistema verifica permisos
6. Se abre main_window con menú
7. Usuario puede navegar a cualquier pantalla

FLUJO 2: USUARIO CREA UNA VENTA
1. Usuario va a: Mesas → selecciona mesa
2. Ve pantalla: Crear Pedido
3. Agrega productos del catálogo
4. Especifica cantidades
5. Hace clic: Guardar Venta
6. Sistema registra en BD
7. Muestra opción: Imprimir ticket
8. Mesa marcada como "pagando"

FLUJO 3: SISTEMA VERIFICA ACTUALIZACIÓN
1. App inicia
2. Lee version.json local (v1.0.1)
3. Se conecta a GitHub
4. Descarga version.json remoto
5. Compara versiones
6. Si hay versión nueva:
   - Muestra diálogo "Actualización disponible"
   - Usuario hace clic "Sí"
   - Descarga .exe nuevo
   - Reemplaza el anterior
   - Reinicia app
7. Usuario tiene versión nueva

FLUJO 4: CIERRE DE CAJA
1. Cajero va a: Caja → Cerrar Caja
2. Sistema calcula:
   - Total de ingresos
   - Total de egresos
   - Diferencias
3. Muestra resumen
4. Genera reporte de cierre
5. Marca caja como "cerrada"
6. Respalda BD automáticamente

MANTENIMIENTO Y SOPORTE
================================================================================

RESPALDO AUTOMATICO:
- La app crea backup automático cada cierto tiempo
- Ubicación: %LOCALAPPDATA%\TECHCRM\backups\
- Formato: crm_system_FECHA.db
- En caso de corrupción: se restaura automáticamente

LOGS:
- Ubicación: %LOCALAPPDATA%\TECHCRM\logs\app.log
- Útil para diagnosticar problemas
- Contiene timestamps y trazas de error

RESTAURACION DE BD:
- Si la BD se corrompe
- Eliminar: %LOCALAPPDATA%\TECHCRM\crm_system.db
- Reiniciar app: recrea BD vacía con migraciones

ACTUALIZACION DE VERSIONES:
- Seguir: ACTUALIZACION.md
- 5 pasos simples
