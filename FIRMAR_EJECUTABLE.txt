3. OPCION A: USANDO SIGNTOOL (Windows SDK)
================================================================================

SIGNTOOL.EXE es la herramienta oficial de Microsoft para firmar código.
Se instala con el Windows SDK.

PASO 1: Instalar Windows SDK
----------------------------
Opción 1 - Visual Studio (si lo tienes):
1. Abre Visual Studio Installer
2. Haz clic en tu versión instalada
3. Haz clic "Modify"
4. Busca "Windows SDK"
5. Actívalo
6. Instala

Opción 2 - Descarga directa:
1. Abre: https://developer.microsoft.com/en-us/windows/downloads/windows-sdk/
2. Descarga la versión más reciente
3. Ejecuta el instalador
4. Elige instalar solo "Windows SDK"
5. Completa la instalación

PASO 2: Verificar instalación
------------------------------
Abre PowerShell y ejecuta:
    signtool /?

Debería mostrar ayuda si está instalado correctamente.

Si no funciona, busca signtool.exe manualmente:
    Get-ChildItem -Path "C:\Program Files" -Recurse -Filter "signtool.exe" 2>$null

PASO 3: Firmar el ejecutable
----------------------------
Abre PowerShell como ADMINISTRADOR y ejecuta:

```powershell
cd "c:\Users\duvan\OneDrive\Desktop\Nueva carpeta\git\CRM"

signtool sign /f "techpixelc-cert.pfx" `
              /p "techpixel2026" `
              /fd SHA256 `
              /t http://timestamp.comodoca.com/authenticode `
              "dist/TECHCRM-POS.exe"
```

ALTERNATIVA (en una línea):
```
signtool sign /f "techpixelc-cert.pfx" /p "techpixel2026" /fd SHA256 /t http://timestamp.comodoca.com/authenticode "dist/TECHCRM-POS.exe"
```

PASO 4: Verificar firma
-----------------------
```powershell
signtool verify /pa "dist/TECHCRM-POS.exe"
```

Debería mostrar:
    SignTool Error: No certificates were found that met all the given criteria.

O si se firmó correctamente:
    Successfully verified: dist/TECHCRM-POS.exe

PASO 5: Verificar con Windows Explorer
---------------------------------------
1. Click derecho en dist/TECHCRM-POS.exe
2. Propiedades
3. Pestaña "Digital Signatures"
4. Debería mostrar la firma

6. TROUBLESHOOTING
================================================================================

PROBLEMA: "signtool is not recognized"
---------------------------------------
CAUSA: Windows SDK no está instalado
SOLUCION: Ver PASO 1 en OPCION A para instalar SDK

PROBLEMA: "Error reading PFX file"
----------------------------------
CAUSA: Contraseña incorrecta o archivo corrupto
SOLUCION:
- Verifica que escribiste bien: techpixel2026
- Verifica que el archivo existe: techpixelc-cert.pfx
- Si persiste, recrea el certificado

PROBLEMA: "Operation Succeeded" pero no aparece firma
------------------------------------------------------
CAUSA: Posiblemente timeout del timestamp server
SOLUCION: Intenta otro servidor de timestamp:
- http://timestamp.comodoca.com/authenticode
- http://ts.globalsign.com/fc1
- http://timestamp.sectigo.com

PROBLEMA: SmartScreen sigue apareciendo después de firmar
----------------------------------------------------------
CAUSA: Es normal para certificados auto-firmados en primeros usos
SOLUCION:
- SmartScreen aprende con el tiempo (10-20 descargas)
- Certificados comerciales evitan esto (cuestan dinero)
- Los usuarios pueden confiar en tu app

PROBLEMA: Certificate expired
------------------------------
CAUSA: El certificado techpixelc-cert.pfx venció
SOLUCION: Crear uno nuevo (ver receta abajo)

7. CREAR CERTIFICADO NUEVO (Si es necesario)
================================================================================

CREAR CERTIFICADO AUTO-FIRMADO CON POWERSHELL
-----------------------------------------------

```powershell
# Cambiar contraseña si es necesario
$password = ConvertTo-SecureString -String "techpixel2026" -Force -AsPlainText

# Crear certificado válido por 5 años
$cert = New-SelfSignedCertificate `
    -DnsName "Tech Pixel C" `
    -Type CodeSigning `
    -CertStoreLocation "cert:\CurrentUser\My" `
    -NotAfter (Get-Date).AddYears(5) `
    -Subject "CN=Tech Pixel C, O=Tech Pixel C, C=MX"

# Exportar a archivo .pfx
Export-PfxCertificate `
    -Cert $cert `
    -FilePath "techpixelc-cert.pfx" `
    -Password $password

Write-Host "Certificado creado: techpixelc-cert.pfx"
```
